# Survival Shooter

A simple pygame top-down shooter with enemy waves, a final boss, shot cooldowns,
and a points shop.

## Run

```bash
pip install -r requirements.txt
python main.py
```

## Controls

- `ENTER` starts the game from the menu.
- `WASD` moves the player.
- Left mouse click shoots toward the cursor.
- `TAB` opens or closes the shop.
- `1`-`4` buys shop upgrades while the shop is open.
- `R` restarts after game over or victory.
- `M` returns to the menu after game over or victory.
- `Q` quits.
